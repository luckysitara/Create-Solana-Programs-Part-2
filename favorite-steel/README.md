# Favorites

This program is a basic app using the Steel framework, implementing Program Derived Addresses (PDAs) to securely store data for individual users. It ensures each user can only modify their own data through Steel's account verification.

This example is also used in the [Solana Professional Education course](https://github.com/solana-developers/professional-education).

## Usage

1. **Build the program**:  
   ```bash
   steel build
   ```

2. **Deploy the program**:  
   Deploy to a localnet with:
   ```bash
   steel deploy
   ```
   For devnet or mainnet deployments, configure the cluster in the Steel config file.

3. **Run tests**:  
   Run all tests to verify program functionality:
   ```bash
   steel test
   ```
